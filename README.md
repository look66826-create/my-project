# My Project

A personal software project for learning, development, and experimentation.

## Overview

This is the initial version of a simple task-management web application. The project will be expanded with additional features during development.

## Current Features

- Add tasks
- Mark tasks as completed
- Delete tasks
- Simple responsive interface
- Tasks are saved in the browser

## Planned Improvements

- User accounts and authentication
- Cloud/database storage
- Better task organization
- Search and filtering
- Dark mode
- Backend API

## Getting Started

Open `index.html` in a modern web browser.

## Tech Stack

- HTML
- CSS
- JavaScript
